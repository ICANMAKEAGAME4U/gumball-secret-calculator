# gumball-secret-calculator
🎮 Gumball Secret Calculator Game 🎮
=====================================

A fun interactive calculator with a hidden secret mini-game, inspired by *The Amazing World of Gumball*!

## 🔓 How to Unlock the Secret Game

1. **Open the calculator** - You'll see a normal-looking calculator interface
2. **Enter the secret code**: `5318008`
3. **Press the equals button** `=`
4. **🎉 The secret game launches!** - Gumball's Coin Rush!

## 🎯 Gumball's Coin Rush Gameplay

Once you unlock the secret game, you'll play as Gumball trying to catch falling coins while avoiding enemy obstacles!

### Controls:
- **Arrow Keys** or **A/D keys** - Move left and right
- **Escape** or click **"Exit Game"** - Return to the calculator

### Objective:
- **Catch coins** (yellow circles with $) to earn points
- **Avoid red enemies** to keep your lives
- **Survive 3 lives** to see how high you can score
- **Difficulty increases** as you level up!

### Scoring:
- Each coin caught: **10 points × current level**
- Every 100 points: **Level up!**
- Level up: Coins and enemies fall faster

### Game Features:
✅ Progressive difficulty levels
✅ Enemy AI that chases the player
✅ Score tracking and statistics
✅ Visual feedback and animations
✅ Responsive design for all devices
